# 衢州市妇幼保健院召开全体党员大会完成党委纪委换届选举工作

> 更新时间：2026-09-17 (UTC+8)

//

12月7日晚，衢州市妇幼保健院召开全体党员大会，进行党委、纪委换届选举。市卫健委党委副书记、副主任雷晓燕，市卫健委组织人事处处长王小帅到会指导。医院领导班子成员和84名正式党员参加会议，会议由院党委副书记何俊英主持。

大会在雄壮的国歌声中开幕。

院党委书记王颖斌代表上届党委作题为《实干担当 跨越赶超 奋力谱写高质量发展新篇章》党委工作报告，认真回顾总结了上届党委工作，梳理经验和不足。他指出要以习近平新时代中国特色社会主义思想为指导，深入学习贯彻落实党的二十大精神，围绕建设四省边际公共服务桥头堡目标定位，树立新发展理念，以高质量党建引领高质量发展为主线，以加强领导班子和人才队伍建设为重点，以推动党建与业务深度融合为载体，以强化党风廉政建设为保证，以提振宣传思想文化精气神为支撑，在推动中心任务和各项重点工作上提质增效，全力打造“衢有善育”品牌，积极为“浙有善育”金名片凝炼衢州经验，并以“大健康”的理念不断完善生育友好型医院建设，持续创新母婴医疗保健全流程服务模式，在奋力推进“两个先行”中展现衢州妇幼独特风采。

纪委书记徐舜代表上届纪委作工作报告。她指出，要紧紧围绕党的领导、党的建设、全面从严治党、党风廉政建设和反腐败斗争，紧紧围绕维护党中央权威和集中统一领导，履行党章赋予的监督执纪问责职责，打造一支具有专业能力和品牌特色的妇幼纪检铁军，以更加奋发向上、求真务实、开拓创新、勇于担当的作风和姿态，为维护医院改革、发展、稳定的大局，促进医院全面高质量发展做出新的更大的贡献！

会上，市卫健委组织人事处处长王小帅宣读了委党委同意我院党委、纪委换届选举的批复文件。

会上，全体党员审议通过了医院党委、纪委工作报告，表决通过了大会选举办法（草案）以及监票人和计票人名单。大会通过无记名投票和差额选举方式，选举产生新一届党委委员和纪委委员。随后，召开党委、纪委第一次全体会议，进行党委书记、副书记和纪委书记选举，王颖斌同志当选为党委书记，何俊英同志当选为党委副书记；徐舜同志当选为纪委书记。

王颖斌书记代表医院新一届党委作表态发言。他表示，新一届党委在委党委的正确领导下，一定会进一步注重学习、提高素质，不断提升医院领导班子的政治能力；进一步加强团结、联系群众，不断增强医院领导班子的服务能力；进一步转变作风、廉洁自律，不断发挥医院领导班子的表率作用；进一步求真务实、开拓创新，不断提高医院领导班子的管理水平。

他承诺，新一届领导班子绝不辜负组织的关怀、领导的厚望和群众的信任，必将会齐心协力，努力工作，带领医院在新的历史机遇中实现新的跨越！

市卫健委党委副书记、副主任雷晓燕代表市卫健委党委对当选的党委、纪委班子成员表示热烈祝贺，并提出了三点要求和希望：

**一是要切实抓好政治理论学习**
院党委要把学习贯彻党的二十大精神作为当前政治理论学习的首要任务，统筹安排党的二十大精神学习及宣传活动，真正使党的二十大精神入脑入心，强化理论与实践相结合，将党的二十大精神转化为推动工作、谋划事业发展的强大动力。

**二是要切实抓好党委和纪委自身建设**医院党委班子要严格执行民主集中制，高度重视并自觉维护班子团结，主要负责人要切实担负起班长的职责，善于集中大家的智慧；班子成员既要根据集体决定和工作分工认真履行自己的职责，又要着眼全局自觉维护班子内部团结，不断提升班子合力，要把班子打造成和谐、奋进、奔跑的团队；医院纪委要履行好监督执纪问责职责，聚焦中心工作，持之以恒正风肃纪，坚定不移惩治腐败，不断推动从严治党向纵深发展，为医院高质量发展提供坚强纪律保证。

**三是要切实抓好党支部和党员队伍建设**
医院党委要做好表率，引领医院各支部不断增强战斗堡垒作用；同时要强化党员队伍建设，坚持党员干部轮训制度，扎实开展警示教育活动，不断提升党员的政治素质和党性修养，打造一支信念坚定、政治可靠、素质优良、纪律严明、作用突出的党员队伍，为建设四省边际一流妇幼保健院贡献自己的力量。
